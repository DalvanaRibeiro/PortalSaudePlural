# Saúde Plural Web

Plataforma web responsiva em React, TypeScript e Firebase.

## Forma mais simples no Windows

Extraia o ZIP inteiro e dê dois cliques em `INICIAR-WINDOWS.bat`.

## Pelo terminal

Abra o terminal diretamente nesta pasta, onde está o arquivo `package.json`, e execute:

```bash
npm install
npm run dev
```

O projeto foi configurado para Node.js 18, 20 ou 22 e utiliza versões fixas das dependências para evitar conflito do Vite.

## Firebase

1. Ative Authentication > E-mail/senha.
2. Crie o Firestore Database.
3. Publique as regras do arquivo `firestore.rules`.

## Compilar

```bash
npm run build
```
